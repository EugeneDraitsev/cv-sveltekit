Applied AI work

Telegram AI Agentgithub.com/EugeneDraitsev/telegram-bot-app Open source2015 – Present

LLM agent running in hundreds of Telegram group chats, handling several million messages a month at near-100% uptime.

  • Evaluation from a real incident. After a chat member asked the bot, as a joke, to break into a third party's account, put a cyber-abuse classifier (OpenAI Decisions API) in front of agent commands and wrote a 36-case labelled eval that runs against the live model: injection and obfuscation attacks on the classifier itself, requests that point at earlier messages, and 21 benign look-alikes that must pass. Later closed a bypass through chat history the cases had missed. Write-up.
  • Reply gate. One cheap structured engage-or-ignore call per message, ignoring by default and treating mentions and replies as unreliable hints; each real misfire became a rule or an example in the prompt, pinned by regression tests.
  • Agent loop. Typed tool registry (web search, code execution, image, video and voice generation, memory, tools the bot defines per chat) with round and time budgets owned by the runtime. Per-role models with fallbacks across OpenAI, Anthropic and Google; status, latency, model and fallback source recorded per call.
  • Platform. Routing-only webhook, per-chat FIFO SQS queues, idempotent Lambda workers with Redis leases and dead-letter queues, so a redelivered message never produces a duplicate reply; 750+ automated tests.

Tech: TypeScript, Bun, AI SDK, OpenAI, Anthropic and Gemini APIs, AWS Lambda, SQS, DynamoDB, Upstash Redis, Serverless Framework, grammY
